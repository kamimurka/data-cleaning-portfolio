# Restaurant Orders Data Cleaning & Analysis

## Overview
This repository contains an end-to-end data cleaning, transformation, and preprocessing pipeline for a restaurant ordering dataset built with Python (Pandas). 

> **Note on Data:** To comply with privacy standards, the dataset, transaction records, and company names used in this project were artificially generated using AI. However, **all data cleaning architecture, Pandas logic, Regex patterns, and data pipeline execution were completely authored and implemented by me** to demonstrate real-world data engineering and preprocessing techniques.

## Project Structure (example)
* `01-restaurant-orders-cleaning/`
  * `restaurant_orders.xlsx` — Raw input dataset (uncleaned/generated)
  * `restaurant_orders_cleaned.xlsx` — Processed dataset
  * `main.py` — Data cleaning script and transformation logic
